# Cinematic-Performance-and-Film-Talent-Analysis

## Tools Used
- **Microsoft Excel** (Data Cleaning & Preparation)
- **Power BI** (Data Modelling, DAX & Interactive Dashboard Design)

## Project Overview
This repository features an interactive Power BI dashboard built using a comprehensive **3,000-movie dataset**. Designed with a clean, professional layout for effortless navigation, the dashboard enables entertainment industry leaders and stakeholders to explore box office trends, financial performance, and genre metrics to make data-backed film investment and talent strategy decisions.

## Key Insights
- **High-ROI Genres:** Highlighted which film genres consistently deliver the highest return on investment relative to their production budgets.
- **Financial Trends:** Tracked the correlation between production costs, runtime, and global box office returns across the 3,000-movie dataset.
- **Strategic Decision Support:** Provided a clear visual breakdown to help producers minimize financial risk and optimize resource allocation.
